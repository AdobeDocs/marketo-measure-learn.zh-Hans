# 促销活动对象字段

本课程涵盖[!DNL Marketo Measure]用于将营销活动和营销活动成员映射到营销渠道的Salesforce CRM Campaign对象字段。 了解这些促销活动对象的功能非常重要，因为您需在[!DNL Marketo Measure]中管理和映射离线渠道。
